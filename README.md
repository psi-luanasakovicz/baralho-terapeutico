# 🎴 Jogo de Psicologia - Baralho Terapêutico

Um jogo interativo de psicologia onde os jogadores podem tirar cartas de um baralho especial para descobrir insights.

## Desenvolvimento

```bash
npm install
npm run dev
```

Abre em [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

Os arquivos de produção ficam em `dist/`.

## Estrutura

- `index.html` — página principal
- `src/decks.js` — textos de todos os baralhos e cartas
- `src/script.js` — lógica do jogo
- `src/style.css` — estilos visuais

As cartas são geradas em HTML/CSS — não é necessário usar imagens PNG.
